## ✨ Brand New Architecture & Features
- 💻 **Interactive Dev Console**: Real-time terminal widget previewing status, degree score, client ERP records, and achievements.
- 📦 **Bento Grid Highlights**: "At a Glance" key metrics covering client ERP impact, Gemini AI platforms, and SIH leadership.
- 📁 **Numbered 12-Project Showcase**: Modern numbered cards with category tabs (`All`, `AI & Full-Stack`, `Enterprise & Client`, `Utilities`) and instant search input.
- 📖 **Interactive Career Blueprint Tab Reader**: Dynamic experience selector allowing visitors to click through internships (IIT Kanpur, Freelance Client ERP, AICTE, EduSkills, CertED, SIH).
- 🎨 **Space Grotesk & Plus Jakarta Sans Typography**: Ultra-clean, high-impact aesthetic.
