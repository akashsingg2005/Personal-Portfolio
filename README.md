## 📌 About The Project
Renovated interactive portfolio website for **Akash Kumar Singh**, Full Stack & AI Developer. The website features an interactive neural particle canvas, filterable and searchable showcase for all 12 GitHub projects, detailed internship timeline, technical skills breakdown, and Formspree contact integration.

🔗 **Live Website**: [https://personal-portfolio-akash.vercel.app/](https://personal-portfolio-akash.vercel.app/)

---

## 🚀 Key Features & Renovations
- 🧠 **Interactive Neural Canvas**: Custom HTML5 canvas particle animation responding to cursor movement.
- 🔍 **Real-Time Project Search & Filter**: Instantly filter 12 projects by category (AI & Full Stack, Enterprise & ERP, Utilities) or search by tech stack/keywords.
- 💼 **Experience Timeline**: Highlights internships at IIT Kanpur / EISystems Services, client ERP freelance projects, AICTE EduSkills Python Full Stack internships, and Smart India Hackathon leadership.
- ⚡ **Full Stack & AI Arsenal**: Highlights MERN stack, Google Gemini API, Python/Django, MySQL, MongoDB Atlas, and RESTful APIs.
- 📱 **Ultra-Responsive UI**: Crafted using Tailwind CSS, glassmorphism aesthetics, and custom CSS micro-interactions.
- ✉️ **Integrated Contact Form**: Direct message delivery powered by Formspree API.
